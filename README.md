# My-SVN 轻量级局域网版本管理工具

## 使用方式

### 服务端（在一台固定电脑上运行）

双击 `server.py` 或执行：
```
python server.py
```

启动后自动广播自身地址，无需任何配置。

### 客户端（在任意电脑上运行）

双击 `client.py` 或执行：
```
python client.py
```

然后：
1. 点击 **🔍 自动搜索服务器** 自动发现服务端
2. 选择本地工程文件夹
3. 点击 **💾 保存版本** 提交变更
4. 选中某个历史版本后点击 **🔄 还原选中版本** 回退

## 环境要求

- Python 3.8+
- 所有依赖已列在 `requirements.txt` 中

## 安装依赖（仅首次）

```
pip install -r requirements.txt
```

## 可选：AI 自动备注

在客户端菜单栏「设置」中配置 DeepSeek API Key，即可使用 AI 自动生成中文提交摘要。
